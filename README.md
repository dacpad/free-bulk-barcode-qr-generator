# 🚀 free-bulk-barcode-qr-generator

A completely free, lightning-fast tool to generate single and bulk Barcodes and QR Codes directly in your browser. 

**🌟 Live Demo:** [https://dacpad.in/barcode](https://dacpad.in/barcode)

### ✨ Key Features
* **Single & Bulk Generation:** Generate hundreds of codes in one go.
* **Dual Format Support:** Create both standard Barcodes and modern QR Codes.
* **100% Offline & Secure:** No backend API or server is used. Everything runs locally in your browser ensuring complete data privacy.
* **No Registration Required:** Completely free to use with zero logins or sign-ups.

### 🛠️ Tech Stack
* HTML5
* CSS3
* Vanilla JavaScript (No heavy frameworks)
* JsBarcode (v3.11.5)
* qrcodejs (v1.0.0)
